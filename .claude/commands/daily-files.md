Outlook(https://outlook.cloud.microsoft/mail/)에서 박정은 부장의 Daily sales report 메일을 찾아 첨부 xlsx 2개를 다운로드한다.

## 메일 특징
- 보내는 사람: JungEun Park (박정은 부장, CS Senior Manager, PARKJE@essilor.co.kr)
- 받는 사람: essk-sales@essilor.co.kr (김동혁은 참조 또는 그룹 수신)
- 제목 형식: "Daily sales report ( October-13 )" (영문 월-일)
- 월 마감 메일은 날짜 대신 월만 쓴다: "Daily sales report ( September )"
- 본문: "10월 13일 매출 현황 & 10월 13일 주문 현황 입니다."
- 제목의 날짜는 데이터 기준일이다. 메일은 보통 다음 영업일 오전 10:30~10:50경 도착한다. 예) October-13 메일은 10/14(수) 10:53 도착.
- 주말·휴일에는 메일이 없다. 휴일 뒤 첫 메일에는 휴일 수주가 포함될 수 있다. 예) October-10 메일은 10/12(월)에 오고 "(10/11일 수주 포함)"이 적혀 있다.
- 메일은 Outlook 폴더 02_Sales > Daily Report 에 자동 분류된다. 받은 편지함에 남아 있을 수도 있으니 전체 폴더에서 검색한다.

## 첨부 파일 (xlsx 2개, 파일명은 월 단위로 고정, 일별 누적본)
- Daily Order InTake Report _2026_10(공유용).xlsx (약 19MB) -> 데일리 오더
- Daily Sales Report_2026_10(공유용).xlsx (약 5MB) -> 데일리 세일즈
- 월이 바뀌면 파일명의 _2026_10 부분만 바뀐다. 9월 마감 메일(10/1 도착)에는 _2026_09 파일이 붙어 있다.

## 절차
1. Outlook 웹에서 검색창에 아래를 입력하고 Enter:
   from:PARKJE subject:"Daily sales report"
2. 결과 목록 맨 위(가장 최근) 메일을 연다. 제목의 날짜가 오늘 기준 직전 영업일인지 확인한다.
   - 아직 안 왔으면 "아직 오늘 메일 미도착"이라고 보고하고, 가장 최근 메일로 진행할지 물어본다.
3. 첨부 2개를 각각 "기타 작업 > 다운로드"로 받는다. ("모두 다운로드"는 zip일 수 있으니 개별 다운로드 권장)
4. 저장 경로: %USERPROFILE%\Documents\Stellest_Daily\YYYY-MM-DD\ (YYYY-MM-DD는 메일 제목의 데이터 기준일)
   - Chrome은 기본 다운로드 폴더(%USERPROFILE%\Downloads)에 받으므로, 다운로드가 끝나면 두 파일을 위 폴더로 옮긴다. 폴더가 없으면 만든다.
   - 파일명은 원본 그대로 두고, 폴더명에 기준일을 넣는다.
   - 같은 기준일 폴더에 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 나에게 물어본다.
5. 옮긴 뒤 파일 크기가 위 용량과 비슷한지 확인하고, 두 파일의 시트 이름과 마지막 데이터 날짜를 요약해서 보고한다.
   - 요약은 Stellest 제품 기준으로 한다. 나는 Stellest 매니저이므로 오더·세일즈 모두 Stellest 수량만 본다. 제품/브랜드 구분 컬럼을 찾아 Stellest만 필터하고, 어떤 컬럼으로 필터했는지 함께 보고한다.
   - 여기까지가 이 명령의 범위다. 대시보드 갱신은 하지 않는다.
